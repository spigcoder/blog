# pi 终端 Agent 学习与使用笔记

之前没有正式学习和使用过终端 Agent，最近 pi 比较火，于是上手体验并记录一下。

## 常用命令

1. **执行终端命令**：在 pi 中输入 `! + command` 可以直接运行终端命令；如果不想让 pi 看到某次命令的运行过程和输出，可以使用 `!! + command`。
2. **模型切换**：macOS 上可以用 `Ctrl + L` 切换模型，用 `Shift + Tab` 切换模型的思考模式。
3. **上下文管理**：pi 的上下文管理方式比较特别，是我之前没见过的实现：
   1. 在命令行执行 `pi -c`，可以从最近一次结束的上下文重新运行；
   2. 执行 `pi -r`，可以选择一个历史上下文继续使用；
   3. 上下文以树形结构组织，运行 `/tree` 打开下图界面，选择任意节点即可从该节点继续。

![pi 上下文树形结构](/assets/posts/pi-image-20260822203244962-77c4cebb2d.png)

4. **安装插件**：可以到官网查找需要的插件进行安装；如果只想在某个项目中使用、不想装到全局，可以在命令后加 `-l`，表示安装到当前项目（local）。
5. **btw 插件**：AI 在后台工作时，可以通过 `btw` 命令新开一个窗口与 AI 对话，从而不打断正在进行的工作。
